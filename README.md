# Terminal-Pong  

Консольная реализация классической игры Pong в пошаговом режиме. Проект выполнен в команде из трёх человек в рамках обучения.

## Описание

Консольная игра Pong для двух игроков с использованием ASCII-графики. Управление пошаговое: каждый ход игроки вводят действие, после чего поле перерисовывается. Игра идёт до 21 очка.

| Параметр | Значение |
|----------|----------|
| Поле | 80 × 25 символов |
| Ракетка | 3 символа |
| Мяч | 1 символ |
| Режим | Пошаговый |
| Управление | Клавиатура |

**Управление:**
- `A` / `Z` — левый игрок вверх / вниз
- `K` / `M` — правый игрок вверх / вниз
- `Пробел` — пропустить ход

**Требования**:  
- компилятор gcc  
- стандарт C99 или новее  
- без внешних библиотек  
- статическая память: без malloc, без указателей, без массивов  
- cppcheck и clang-format
